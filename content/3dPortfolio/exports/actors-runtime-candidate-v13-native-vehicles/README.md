# Веб-пакет v13

`vehicles.glb` — библиотека из семи машин. У каждой машины один корневой
узел, один меш, один треугольный примитив и один материал. Обычный
`GLTFLoader` возвращает эти корни как `THREE.Mesh`. Позиции, нормали,
треугольники, габариты и `web_id` совпадают с v12. Текстуры, цвет, фары и
параметры стекла сведены в общий PBR-атлас. Показатель преломления общий.

Модели лежат в библиотеке в исходной точке. Для визуальной проверки
выбери одну модель по `userData.web_id` или разнеси их по сцене. Для
трафика используй геометрию и материал корневого `Mesh` экземпляра.

Восемь проектных зданий находятся в `buildings/` вместе с исходными
метками и платформами. Их модели по-прежнему могут содержать несколько
примитивов с разными материалами. Для них доступен `single-mesh.mjs`.
`building-catalog.json` связывает здания с ID и URL.

Геометрия города, здания и маршруты взяты из v12. Версия и SHA файлов
записаны в `candidate-manifest.json`. SHA города и сети также сверяются
с `scene.json` и `simulation-zones.json`.
