# Несжатый пример города

city.glb экспортирован без Draco и Meshopt из avenue_walking_v05. GLTFLoader может загрузить его без декодеров геометрии. Текстуры встроены в GLB в обычных форматах изображений. Служебные области/очереди не видимая геометрия.

scene.json содержит метки/камеры. mobility.draft.json и pedestrian-areas.draft.json привязаны к этому GLB, но схема движения ещё НЕ прошла runtime-приёмку. Это пример для разработки, не замена рабочего пакета. Production manifest намеренно отсутствует. Исходная сцена и существующий сайт не переключались.
