## Что покрыто

121 направленное автомобильное ребро (раньше 14), включая 49 поворотов.
1028 точек после сокращения с 13676, допуск 2 см в 3D.
Улица проектов, обе поперечные улицы с мостами, западная улица, продолжение
вправо до границы сцены, обе улицы за стартом, южный бульвар, его сужения
и замкнутая южная улица с велосипедными дорожками. Внутридворовые пешеходные
дорожки не превращены в автомобильные; отдельной парковки по местам нет.

Семь автомобильных перекрёстков имеют движения между разными подходами;
старые два управляемых перехода сохранены. На Y55 — три направления с каждого
из четырёх подходов и явная таблица approaches. Все они включены в прежние
сигнальные группы и привязаны к прежним физическим головам/48 линзам.
На остальных новых перекрёстках control=priority и консервативные conflicts;
никаких новых невидимых светофоров не выдумано. Это геометрия/связи, не готовый
план управления движением. conflictsReviewed=false у новых перекрёстков.

## Границы и версии

terminalNodes — optional массив внутри road-network.json:

```json
{
  "nodeId": "node.city.…",
  "kind": "exit",
  "position": [0, 0, 0],
  "endBehaviour": "stop-or-despawn",
  "automaticSpawnAllowed": false
}
```

18 граничных узлов: 9 направлений въезда и 9 выезда. Точки находятся до края
асфальта/ограждения. При достижении конца нельзя продолжать экстраполяцию в поле
или через строительное ограждение. Въезды — возможные начала маршрутов, не
команда немедленно спавнить машины. Существующие два spawnSegments остаются
необязательными проверенными отрезками. Терминальные тупики не имеют
вымышленных тесных разворотов. Обратное направление начинается от отдельного
входного узла; остановку/удаление/возврат пользователя определяет веб-часть.

edges[].id/from/to/points/widthMetres и система координат прежние: метры,
Y вверх, перед -Z. Топология теперь шире. Старый edge.avenue.vehicle.turn.south
убран: вместо него используется обычный перекрёсток Y0 и связанные улицы.
edge.avenue.vehicle.north.2/south.2 сохранены на первых участках до Y55;
после него добавлены edge.city.avenue.north.after55/south.after55.
edge.y55.vehicle.W/E теперь обозначают внутренние прямые движения, а не весь
изолированный проезд. ID остальных прежних рёбер/пешеходов/сигналов сохранены.
Старые полные маршруты и distanceAlong нельзя переносить между версиями вслепую.
Перепривязки controls/demo уже сделаны; сайт должен заново выбрать/рассчитать путь.

routes-demo.json содержит несколько проверяемых последовательностей edgeIds
от прежнего первого ребра к разным улицам, только как примеры. Их можно получить
обычным поиском по from/to. Движение вдоль каждого ребра — линейно по points,
с остатком расстояния при переходе к следующему ребру. Сложная геометрия дороги
не генерируется на сайте. Проекты/видимость/фильтры по-прежнему управляются API.

## Проверки и пределы результата

Сохранённая сцена повторно открыта. Проверены ссылки, один общий уличный граф,
маршруты от основной улицы/внешних въездов к выездам/основной улице. Обратные
входящие полосы конечных улиц закономерно не достижимы от одной основной
полосы без возврата/нового въезда: это граница сети, не оторванный перекрёсток.

2 072 224 пробы опоры по реальным нижним пятнам шин семи моделей из vehicles.glb,
плюс отдельные лучи просвета кузова. Раньше предварительная проверка целого
прямоугольника с зеркалами давала отказы при допустимом нависании над обочиной;
эта предварительная статистика сохранена отдельно, не является финальной ошибкой.
Окончательная проверка колёс и препятствий прошла для всех 121 × 7 сочетаний.
Это выборка с шагом до 30 см, не непрерывный расчёт столкновений или рулевой физики.
Два лишних изгиба обнаружены на обзоре и убраны; проверка теперь также запрещает
петлю, замаскированную под одиночный поворот на перекрёстке.

В городе изменена одна статическая Mesh: подрезаны и закрыты торцы подпорных
стен, выступавшие на западную улицу. Асфальт, здания, UV остальных Mesh, точки
проектов, камера, транспортная и людская геометрия сохранены. Финальные три GLB
реально импортированы Blender, встроенные изображения прочитаны. Четыре
Workbench-кадра из готового GLB осмотрены: это схема, не приёмка материалов сайта.

POSITION/NORMAL/цвета/индексы прочих Mesh сравнены побайтово. Для UV проверен
допуск 1e-7: у одного павильона 28 компонент отличаются на один float32 ULP
(максимум 5.96046448e-8) после повторного экспорта; это записано в отчёте,
поэтому не заявляется побайтовая идентичность всех UV.

Все проверки — мосты закрыты, кадр 1. При разводке мостов сайт должен временно
закрывать пересекающие их пути; новых runtime-привязок анимации мостов этот этап
не добавляет. Многомашинное движение, арбитраж priority/conflicts, фазы светофоров,
блокировка открытых мостов и FPS в браузере ещё не проверены. Сеть остаётся draft;
никакой новый proof «1200 секунд без столкновений» не создан.

## Редактирование и повторение

В Blender открыть указанную новую сцену. Кривые сети находятся в коллекциях
разметки, новые — WEB • full-city vehicle network. Они исключены из рендера/GLB.
Выбрать Curve, Tab, менять точки; общие endpoints синхронизировать штатной командой
разметки. web_edge_from/to и persistent ID не заменять случайными именами.
Для изменения схемы перекрёстка обновлять relationships/controls/approaches,
затем повторять проверки. Сборочный скрипт восстанавливает исходную конфигурацию
этого этапа: не запускать его поверх ручных правок как автоматический updater.
