# Зебры Y55 в текстуре асфальта

Две зебры у Y55 в v07 состояли из 16 плоскостей в 6 мм над асфальтом.
В v08 полосы перенесены в существующий атлас `Road_Paint` и экспортируются
в текстуре асфальта. Отдельные плоскости удалены. Положение полос взято
из исходных прямоугольников. Проверено 240 точек на полосах и 42 между ними.

Два вида импортированного GLB, сверху и с уровня улицы, лежат рядом с
`Editable_City_Crosswalks.blend` в `outputs/City_Web_Contract/crosswalk_depth_v01`.
В веб-проекте кандидат доступен как `/content/3dPortfolioMy2/exports/actors-runtime-candidate-v08`.
На момент сборки URL по умолчанию указывает на v07.
